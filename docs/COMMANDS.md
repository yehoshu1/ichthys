# Commands Reference

List of available Slash Commands for the ΙΧΘΥΣ bot.

## Public Commands
These commands are available to all members.

| Command | Description | Usage |
| :--- | :--- | :--- |
| `/rank` | View your current level, XP, and rank card. | `/rank [user]` |
| `/leaderboard` | View the top 50 members sorted by XP. | `/leaderboard` |

## Utility Commands

| Command | Description | Usage |
| :--- | :--- | :--- |
| `/ping` | Check the bot's latency and WebSocket ping. | `/ping` |

## Configuration Commands
These commands require **Administrator** permissions.

| Command | Description | Usage |
| :--- | :--- | :--- |
| `/config sync` | Manually sync database users with current server members. | `/config sync` |
| `/welcome test` | Test a welcome message trigger to see how it looks. | `/welcome test [template]` |
| `/level set` | Manually set a user's level or XP. | `/level set <user> <level>` |

> **Note**: Most configuration is done via the **Web Dashboard** for a better experience.
