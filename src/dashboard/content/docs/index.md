ΙΧΘΥΣ (Ixoye) is a feature-rich Discord bot with a comprehensive web dashboard
for community management — welcome messages, verification, leveling, events,
polls, moderation, and more.

## Where to start

- **[Getting Started](/docs/getting-started)** — install dependencies,
  configure Discord and the database, and run the bot for the first time.
- **[Dashboard](/docs/dashboard)** — tour of the web dashboard and how each
  feature page works.
- **[Commands](/docs/commands)** — every slash command, its options,
  required permissions, and examples.
- **[Feature Guides](/docs/modules)** — module-by-module operations guide
  for moderators and server managers.
